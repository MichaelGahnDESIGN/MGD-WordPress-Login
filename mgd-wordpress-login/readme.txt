Ein richtig schöner Login mit Templates, Animationen und eigenen Farben, Logo und Hintergrund. Ohne externe Dienste.

== Description ==

Du wählst ein Template, passt Farben, Logo und Hintergrund an und siehst das Ergebnis sofort live.

* 8 kostenlose Layouts, jedes mit eigenen Effekten
* Effekte frei wählbar: Partikel, Lichtkegel, Karten-Effekte, Position
* Eigene Farben, eigenes Logo, eigenes Hintergrundbild
* Live-Vorschau im Backend (Desktop, Tablet, Handy)
* Keine externen Schriften, keine CDN-Skripte, keine fremden Tracker

Meldet sich höchstens einmal am Tag bei theme.michael-gahn.de (Plugin, Version, Shopsystem, Domain, zufällige ID). Abschaltbar in den Einstellungen.

Updates kommen über theme.michael-gahn.de und GitHub. Vor dem Einspielen wird die Datei mit einer Prüfsumme (SHA-256) geprüft.

== Installation ==

1. ZIP-Datei aus den Releases auf GitHub laden.
2. In WordPress: Plugins → Installieren → Plugin hochladen.
3. ZIP auswählen, Installieren, dann Aktivieren.
4. Links im Menü erscheint „MGD Login“.
